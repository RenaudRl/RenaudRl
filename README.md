### 🎯 About

BTC Studio builds the complete stack for immersive Minecraft servers.

We maintain a growing ecosystem of **free & open-source TypeWriter extensions** and **custom Paper/Velocity server forks** for the Minecraft community. Everything here is **GPLv3** — use it, fork it, build on it.

> 🔗 **Looking for more?** Visit **[borntocraftstudio.net](https://borntocraftstudio.net)** for premium extensions, resources, and the full BTC ecosystem — or browse the **[documentation](https://docs.borntocraftstudio.net)** to explore every extension in detail.

### 🏗️ Server Infrastructure

<table>
<tr>
<td width="50%" valign="top">

#### [🧩 BTC Core](https://github.com/RenaudRl/BTC-CORE-Fork)
<sub>Paper 26.2 server fork, built on AdvancedSlimePaper</sub>

- **220 → 33.8 ms MSPT** measured with 50 players on 50 SlimeWorld islands
- Redstone compiler **≈4.8× faster than Alternate Current**, with zero neighbour updates
- 57 NMS performance hooks shipped as Paperweight feature patches
- Zero Features — strip vanilla recipes, advancements and stats without breaking the systems
- Public API: `dev.btc.core:api`

</td>
<td width="50%" valign="top">

#### [🛰️ BTC Velocity](https://github.com/RenaudRl/BTCVelocity)
<sub>Velocity proxy fork for the BTC network</sub>

- Minecraft **26.2** (protocol 776)
- Native permission resolver — no LuckPerms dependency
- Versioned `btc:bridge` protocol between proxy and backends
- Pixel-accurate MOTD alignment, Redis/Valkey/Dragonfly, PostgreSQL
- Public API: `dev.btc.velocity:api`

</td>

### 📜 Licence

Everything above is **GPL-3.0-or-later**. Run it, fork it, build on it — including commercially.

Extensions ship a **linking exception** so they can be combined with the TypeWriter engine, which is not free software. Each repository carries a `NOTICE.md` with the full attribution and the statement of modifications the GPL requires.

The **Born To Craft** and **BTC Studio** names and logos are not covered by the licence — fork the code freely, but rebrand your fork.
